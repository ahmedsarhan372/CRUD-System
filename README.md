# CRUD System

A responsive product catalog for creating, viewing, searching, editing, and deleting product records.

## Features

- Add and validate product details
- Preview an optional product image
- Search by product name, category, description, or price
- Edit and delete products
- Save the catalog in this browser using local storage

## Run locally

Open [index.html](./index.html) in a browser. Keep the `css`, `js`, and `images` folders in their existing paths.

Products are stored in the browser and do not sync to another browser or device. Clearing this site's browser data removes the saved catalog.
